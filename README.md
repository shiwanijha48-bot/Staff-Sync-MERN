# StaffSync

**Modern HR Management Solution — MERN stack**

StaffSync brings employee self-service and people operations together in a bright, responsive, light-mode interface. It includes a polished public landing page and four role experiences: Employee, Manager, HR and Admin.

## Quick start
- Backend: `cd server` → `npm install` → create `server/.env` from `.env.example` → `npm run dev`
- Frontend in a second terminal: `cd client` → `npm install` → `npm run dev`
- Visit `http://localhost:5173`; backend health check is `http://localhost:8000/api/health`.

Read [PROJECT_GUIDE.md](PROJECT_GUIDE.md) for module coverage, role security and initial administrator setup. Never commit `.env` or share database credentials.
